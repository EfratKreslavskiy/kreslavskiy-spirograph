### Spirograph Midterm Project

This project follows the Model-View-Conroller (MVC) design pattern,
with a model that stores parameters, a view for rendering the GUI,
and a controller for handling user input.
The program calculates coordinates and renders the design using line segments,
forming a spirograph based on given parameters.
